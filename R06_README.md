# 🏫 Collège Pasteur — Portail EPS Numérique

Portail web multi-pages centralisant l'ensemble des outils pédagogiques numériques du cours d'**Éducation Physique et Sportive** du Collège Pasteur.

---

## 🌐 Structure du portail

Le portail est organisé en **6 sections** accessibles via des onglets de navigation :

| Onglet | Contenu |
|---|---|
| 🏃 APSA | Activités sportives classées par champs d'apprentissage |
| 🗺️ EPI · Sortie · Voyage | Projets interdisciplinaires et voyages scolaires |
| 🏅 UNSS | Applications Union Nationale du Sport Scolaire |
| 📋 Coordination EPS | Outils de gestion du département EPS |
| 👨‍🏫 Professeur Principal | Suivi de classe et orientation |
| 📂 Répertoire | Tous les sites par ordre alphabétique |

> 🔐 **Espace Perso** : accessible en cliquant **5 fois** sur le logo EPS en haut à gauche. Non visible dans la navigation principale.

## 🚀 Déploiement

1. Déposer `index.html` à la racine d'un dépôt GitHub
2. Activer **GitHub Pages** (`Settings > Pages > Deploy from branch > main`)
3. Accessible à `https://<username>.github.io/<repo>/`
